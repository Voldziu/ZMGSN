Prepare a literature review on the topic "$topic".

The finished review must meet these requirements:
- It covers $n_papers distinct arXiv papers on the topic, each submitted between $date_from and $date_to.
- Each paper's summary is a few sentences that reflect the paper's full text, not only its abstract or search result. A paper whose full text is not available must be replaced by another paper.
- It is saved to the Markdown file reviews/review.md with exactly this structure:
  - A first-level heading with the topic.
  - One second-level section per paper, headed "## <number>. <exact paper title>". It contains the paper's APA reference on a single line (ending with its arXiv URL https://arxiv.org/abs/<id>) followed by the summary.
  - A final section "## Bibliography" with a bullet list of the same APA references, one per paper.

When the review is saved, reply with its path.
