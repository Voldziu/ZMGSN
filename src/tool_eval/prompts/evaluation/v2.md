- Find $n_papers distinct arXiv papers on the topic. Only papers submitted between $date_from and $date_to count; the search tools already apply this window.

- Summarize each paper in a few sentences, based on its full text.
- Save the review to the Markdown file reviews/review.md with exactly this structure:
  - A first-level heading with the topic.
  - One second-level section per paper, headed "## <number>. <exact paper title>". It contains the paper's APA reference on a single line (ending with its arXiv URL https://arxiv.org/abs/<id>) followed by the summary.
  - A final section "## Bibliography" with a bullet list of the same APA references, one per paper.
